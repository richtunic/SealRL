# Known issues and future fixes

- TikTok photo-post detection depends on metadata exposed by TikTok's web response. Platform changes can require an extractor update.
- Music-backed TikTok slideshow creation is available only when TikTok exposes a downloadable audio track.
- Some Android media providers can take a short time to refresh “Recents” even after MediaStore is updated.
- Social-network downloads can still require refreshed login cookies when a provider expires or invalidates the current session.
