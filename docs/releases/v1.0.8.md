## Español

- Nueva navegación inferior para Inicio, Descargas y Ajustes, con filtros para encontrar las descargas por estado.
- Pantallas de inicio y ajustes renovadas, iconos de plataformas en la cola y el historial, y logo de SeaRL ajustado para mostrarse completo en el lanzador.
- Pegado de varios enlaces mejorado, incluido el teclado Samsung.
- Mejor manejo de enlaces compartidos de Facebook y Threads y de las cookies de sesión.
- yt-dlp integrado actualizado a la versión estable 2026.08.19; las nuevas instalaciones usarán el canal estable de actualización.
- Una sola APK universal para esta versión.

## English

- New bottom navigation for Home, Downloads, and Settings, with status filters for downloads.
- Refreshed home and settings screens, platform icons in the queue and history, and a launcher adjustment that keeps the SeaRL logo visible.
- Improved pasting of multiple links, including from Samsung Keyboard.
- Improved handling of Facebook and Threads share links and session cookies.
- Updated bundled yt-dlp to stable version 2026.08.19; new installs use the stable update channel.
- One universal APK for this release.
