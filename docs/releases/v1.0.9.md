## Español

- Los posts públicos de Instagram con fotos o carruseles se leen desde el embed cuando la API de medios requiere iniciar sesión; cada foto se descarga en su formato original.
- La cola vuelve a procesar tareas pendientes al abrir la app y atiende las que se añaden mientras termina una descarga.
- Las filas de la cola muestran un icono de plataforma en lugar del badge de texto; se redujo el tamaño de los iconos de plataforma dentro de SeaRL.
- Una sola APK universal para esta versión.

## English

- Public Instagram photo posts and carousels use the embed when the media API requires sign-in; each photo downloads in its original format.
- The queue resumes pending tasks when the app opens and picks up tasks added while a download finishes.
- Queue rows show a platform icon instead of a text badge; platform icons inside SeaRL are smaller.
- One universal APK for this release.
